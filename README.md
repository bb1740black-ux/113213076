# 投稿審查系統

這是期中個人專題，使用 FastAPI 和 SQLite 製作。從首頁選擇作者或編輯身分，即可操作投稿與審查流程。

## 功能

- **作者**可查看稿件的類別、標題與審查狀態，新增或編輯稿件、刪除草稿，以及送出投稿。
- **編輯**可查看待審清單上的作者、類別與標題，點進去閱讀全文，再選擇通過或退回。
- **稿件狀態**：新增時為「編輯中」，送出後變成「審查中」。退回會回到「編輯中」，通過後顯示「已通過」。

## Windows 啟動方式

下載專案後，在放有 `main.py` 和 `requirements.txt` 的資料夾開啟 PowerShell，執行：

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn main:app
```

啟動後，用瀏覽器開啟 <http://127.0.0.1:8000>。第一次操作稿件時，程式會自動建立 SQLite 資料庫。

## Demo 流程

1. 以作者身分新增一篇稿件，修改內容後送出投稿。
2. 切換到編輯身分，從待審清單開啟全文並退回稿件。
3. 回到作者頁面，修改後再次送審。
4. 切換到編輯身分按「通過」，再回作者清單確認狀態為「已通過」。
5. 另外新增一篇測試草稿，展示刪除功能。
